# 안녕하세요, 윤입니다

동국대학교에서 개발합니다. 서버를 만들고, 그 서버가 도는 인프라까지 직접 다룹니다.
단순하게 굴러가고 오래 가는 구조를 좋아해요.

- 동국대 GPU 서버실 관리 시스템의 백엔드와 인프라를 개발하고 운영합니다
- 설치 없이 기기끼리 파일을 바로 주고받는 웹앱 Radius를 만들고 있어요

## Projects

- **[Radius](https://github.com/yoon6yo/radius)**: 설치·가입 없이 가까운 기기끼리 WebRTC로 파일을 직접 전송합니다. 수십 GB도 끊겨도 이어받아요.
- **[admin_be](https://github.com/CSID-DGU/admin_be)** · **[admin_infra](https://github.com/CSID-DGU/admin_infra)**: GPU 서버 신청부터 계정 생성, 만료 안내, 자원 회수까지 자동화한 시스템의 백엔드(Spring Boot, Redis)와 Kubernetes 인프라.
- **[artrun-be](https://github.com/GDSC-DGU/artrun-be)**: GPS 위에 그림을 그리는 AI 아트 러닝 코스 생성 서비스 백엔드 (GDSC DGU).
